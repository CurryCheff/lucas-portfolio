# Lucas Portfolio

Personal portfolio site for Lucas Musungo — Software Engineer.

## Stack

- Vanilla HTML / CSS / JavaScript
- [Vite](https://vite.dev) — dev server and build
- [GSAP](https://gsap.com) + ScrollTrigger — scroll animations
- [Lenis](https://lenis.darkroom.engineering) — smooth scrolling

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Structure

| Path | Purpose |
|------|---------|
| `index.html` | Page markup — hero, work, about, contact |
| `style.css` | All styles, design tokens defined in `:root` |
| `app.js` | Animations, smooth scroll, custom cursor, nav |
| `lib/cursor-grid.js` | Cursor-reactive canvas grid used in the hero |
| `lib/lenis/` | Vendored Lenis smooth-scroll build |
